## The word list

The app's French word list (5,007 words with English meanings, forms and
example sentences) is licensed
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Download it
from the [latest release](https://github.com/Brock-Chain/glancefrench/releases/latest);
`LICENSE.txt` inside the zip names its sources (Wiktionary through
Kaikki.org, Tatoeba, FrequencyWords) and the changes made.

The app's code is not in this repository.
